# DoomBC for Foundry — Roadmap

Цель проекта: создать **самостоятельную игровую систему DoomBC для Foundry VTT с нуля**.

DoomBC не зависит от Apex Heresy (`dark-heresy`). Apex и другие системы Foundry могут использоваться только как технический референс для изучения API, UI и подходов к автоматизации.

Источник правил: `DoomBC_Core.pdf` (506 страниц).

## Статусы

- ✅ — реализовано и проверено в Foundry
- 🟡 — частично реализовано
- 🛠 — в работе
- ⬜ — ещё не начато
- 🧪 — реализовано, требуется игровое тестирование
- ➖ — оставляем ручным / автоматизация нецелесообразна

## Принцип разработки

Сначала строим самостоятельный системный каркас DoomBC. Создание и развитие персонажа можно развивать параллельно с боевым ядром, если механика не зависит от ещё не реализованных подсистем. Для Талантов разделяем **покупку/данные** и **автоматизацию эффектов**: покупку, стоимость и prerequisites можно реализовать заранее, а боевые и специальные эффекты подключаем после появления базовых механик, на которые они опираются.

Локальная разработка ведётся напрямую из `{Foundry User Data}/Data/systems/doombc/`. GitHub используется как хранилище проверенных этапов, а не как обязательный промежуточный шаг для каждого теста.
